# 量化研究流程与统计口径

## 1. 先判断问题类型

| 类型 | 要回答的问题 | 最低交付 |
|---|---|---|
| 描述性统计 | 历史上出现了什么 | 定义、样本、分布、分组结果 |
| 关系分析 | 两个或多个变量是否共同变化 | 相关系数、区间稳定性、混杂因素 |
| 预测研究 | 当前信息能否预测未来结果 | 时间切分、基准模型、样本外表现 |
| 策略研究 | 规则扣除成本后是否可交易 | 交易规则、成交模型、风险与稳健性 |
| 指标开发 | 如何计算和展示某个量 | 指标定义、边界行为、可视化 |
| 策略实现 | 如何把规则写成脚本 | 完整代码、信号时点、执行假设 |

## 2. 研究定义卡

任何统计或回测开始前写清：
- 标的范围及纳入/剔除标准。
- 数据来源、字段、频率、时区和可用区间。
- 价格是前复权、后复权、不复权还是总回报口径。
- 交易日历、缺失值和异常值处理。
- 样本单位：交易日、标的、事件、交易笔数或持有区间。
- 变量、阈值、边界条件、观察窗口和去重规则。
- 统计量、基准、置信区间或检验方法（适用时）。
- 结果可以支持的结论与不能支持的结论。

定义必须可被另一位研究者按同样数据复现。若定义含糊，先补齐定义，不急着生成结果。

## 3. 形态和阶段识别

- 将形态拆成可计算条件，明确时间顺序、阈值、容差和最短持续时间。
- 识别阶段时必须说明起点、终点、确认条件和未形成结构点时的处理。
- 使用 pivot 高低点时，确认 pivot 通常需要后续 K 线；历史图上回填标签不代表当时已知，策略信号必须延迟到确认时点。
- 多个形态可能重叠时，规定优先级或允许多标签，不能在统计时临时挑选。
- 对高开/平开/低开等分类，阈值应基于前收盘计算并固定单位。
- 对日内走势分类，必须说明使用的 K 线周期、形态识别容差和分类冲突处理。
- 若用户已定义固定类别，保留原类别；未经确认不擅自合并或新增类别。

## 4. 相关性与因果边界

- Pearson 衡量线性相关，Spearman 衡量秩相关；均不自动代表因果关系。
- 价格水平常带趋势，资产相关性优先检查收益率序列而不是直接对价格水平计算。
- 相关性应考虑滚动窗口、不同市场阶段和异常事件。
- 同期相关不能推断领先/滞后关系；滞后相关需要明确时间方向并控制多重检验。
- 若存在共同驱动因素、行业暴露或市场 beta，说明混杂风险。

## 5. 统计检验与多重比较

- 先明确原假设、备择假设、显著性水平和统计单位。
- 报告效应大小与不确定性，不只报告 p 值。
- 大量标的、参数、窗口或形态同时搜索会增加偶然显著结果；应说明多重比较风险，必要时使用校正或独立验证集。
- 时间序列存在自相关、异方差和波动聚集时，不能机械套用独立同分布假设。
- 样本很小时优先展示原始样本数、分布和区间，不夸大统计推断。
- 统计显著不等于经济显著，更不等于扣除成本后可交易。

## 6. 策略候选池管理

每个策略使用唯一名称和版本，至少保存：
- 假设和经济逻辑。
- 入场、退出、仓位和风险规则。
- 参数及其来源。
- 数据范围和脚本版本。
- 开发区间、验证区间、最终测试区间。
- 结果、失败原因、限制和状态。

状态建议：想法、待定义、待实现、待回测、待验证、样本外通过、观察中、暂停、淘汰。若数据库没有对应选项，在项目详情写明子状态，不伪造数据库状态。

## 7. 输出原则

先给最重要结论，再给口径、结果和限制。将「没有发现证据」与「证明不存在」区分开。没有数据时可以提出可检验方案，但不得编造统计结果。
