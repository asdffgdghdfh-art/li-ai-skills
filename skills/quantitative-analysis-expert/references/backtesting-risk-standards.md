# 回测、绩效与风险评估标准

## 1. 先定义成交模型

每个策略必须明确：
- 信号在盘中、收盘还是收盘后生成。
- 信号何时可被真实交易者观察到。
- 成交发生在当根收盘、下一根开盘、下一交易日开盘，还是触发价。
- 价格使用开盘、收盘、限价、止损价或其他模型。
- 同一根 K 线同时触发止盈和止损时如何处理。
- 跳空穿越止损价时如何成交。
- 资金不足、整手限制、最小交易单位和部分成交如何处理。
- 是否允许做空、杠杆、加仓、反手或多标的同时持仓。

成交假设必须保守且可解释。仅凭日线 OHLC 无法知道日内先触及止盈还是止损时，应采用保守处理或更高频数据验证。

## 2. A 股 ETF 特别检查

- 模拟 T+1：当日买入的份额通常不能当日卖出，具体产品规则需核实。
- 考虑交易时段、停牌、涨跌停、流动性和成交量约束。
- 计入券商佣金、最低佣金、买卖价差和滑点；适用税费按产品与市场规则确认。
- ETF 费用、申赎机制、分红和复权处理应与数据源一致。
- 不把收盘价信号和同一收盘价成交混为一谈，除非执行模型有可实现的收盘成交依据。
- 若历史样本包含已清盘、合并或更名 ETF，检查幸存者偏差和标的池回溯构造。
- 研究中不默认存在融券或做空能力；需要做空时先核实可行性。

## 3. 绩效指标

| 指标 | 解释 | 注意事项 |
|---|---|---|
| 总收益 | 区间资金增长 | 说明是否含分红、费用 |
| CAGR | 复合年化收益 | 明确年化天数口径 |
| 最大回撤 | 权益曲线从峰值到谷值的最大跌幅 | 必须基于连续权益曲线 |
| 波动率 | 收益序列的年化标准差 | 说明日频/周频及年化系数 |
| Sharpe | 超额收益相对波动 | 说明无风险利率和收益频率 |
| 胜率 | 盈利平仓笔数 / 全部平仓笔数 | 不反映盈亏幅度 |
| 平均盈亏比 | 平均盈利交易 / 平均亏损绝对值 | 说明按交易笔数还是金额加权 |
| 利润因子 | 总盈利 / 总亏损绝对值 | 总亏损为零时不可按普通有限数解释 |
| 单笔期望 | 每笔交易平均净收益或 R 值 | 明确是否扣费、如何计量 |
| 换手率 | 交易金额相对资产规模 | 说明计算口径 |
| 市场暴露 | 持仓时间或资金处于风险中的比例 | 有助于解释收益来源 |

最低报告：总收益、年化收益、最大回撤、交易次数、胜率、平均盈亏、盈亏比、利润因子、单笔期望、换手率和基准比较。无法计算的指标标记为未计算。

## 4. 基准比较

- 默认考虑买入持有基准；基准应使用相同标的、相同区间和可比成本口径。
- 多资产轮动可使用明确的等权、固定权重或用户指定基准。
- 同时报告策略与基准的收益、回撤和风险调整表现。
- 不用不相关的指数或不同样本区间做夸张比较。

## 5. 防过拟合验证

至少考虑：
1. 按时间顺序切分开发、验证和测试区间。
2. 测试区间只在规则和参数锁定后使用。
3. 参数邻域检查：附近参数是否也能工作，避免只在单点最优。
4. 分市场状态检查：趋势、震荡、快速下跌、高波动等。
5. 成本压力测试：提高佣金、价差和滑点后观察退化程度。
6. 滚动或 walk-forward 验证，检查不同时间段的一致性。
7. 多策略、多参数搜索时说明试验次数和数据窥探风险。

样本外结果差时，不通过反复调整测试集参数来「修好」测试集。应将其作为新研究假设，重新划分未来未见数据。

## 6. 风险优先评估

策略评估应回答：
- 最大回撤发生在哪段时间，持续多久？
- 最大单笔亏损和连续亏损是多少？
- 收益是否集中在少数交易或少数年份？
- 成本增加后是否失去优势？
- 策略是否依赖极少数参数、个别 ETF 或特定行情？
- 仓位是否在高相关资产间重复暴露？
- 策略是否可能因流动性、跳空或交易限制无法成交？

优先保留风险可解释、回撤可承受、逻辑清晰和跨阶段稳定的候选方案，不按收益单指标排名。

## 7. 回测结果分级

- 逻辑检查通过：规则无明显矛盾，尚未完成真实回测。
- 回测初步通过：历史样本结果达到预设条件，但仍可能过拟合。
- 稳健性待验证：完成基础成本和参数检查，仍缺独立样本外证据。
- 样本外验证通过：在预先留出的样本外区间达到事先设定的标准。
- 实盘观察：仅表示进入小规模观察阶段，不代表未来有效。
- 淘汰/暂停：结果不支持继续投入，保留失败记录。

禁止将「历史回测盈利」写成「策略保证盈利」或「未来有效」。
