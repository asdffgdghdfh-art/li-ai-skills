# 控制理论与网络化控制论文写作指南

本指南是 academic-paper-writing 的专业补充资料，适用于控制理论、非线性控制、网络化控制、无人系统、时滞系统、自适应控制、滑模控制、神经网络控制和事件触发控制等方向。

本指南只规范如何表达已经完成并核实的研究，不替代数学推导、定理证明、仿真或实验。

---

## 1. 常见论文结构

以下是常见结构，不是强制模板。最终以目标期刊的格式和论文实际内容为准。

| 章节 | 核心任务 | 写作重点 |
|---|---|---|
| Title | 准确表达研究对象与方法 | 避免过度包装 |
| Abstract | 概括问题、方法、理论结果和验证 | 只写全文已证实内容 |
| Introduction | 解释研究动机和本文贡献 | 背景—进展—不足—本文工作 |
| Preliminaries | 给出必要定义、引理和数学工具 | 只保留后文实际使用的内容 |
| Problem Formulation | 定义系统模型、假设和控制目标 | 模型、约束、目标必须清楚 |
| Controller Design | 说明控制器或算法如何构造 | 设计逻辑、控制律、辅助变量 |
| Stability Analysis | 证明闭环系统性质 | 定理条件、推导链、结论边界 |
| Simulation / Experiments | 验证方法 | 设置、对比、指标、结果 |
| Conclusion | 总结贡献和局限 | 不引入正文没有的新结果 |

## 2. Introduction 的论证链

建议按以下逻辑组织，而不是把所有相关工作堆在一起。

### 第一部分：研究背景
说明研究对象为什么重要、实际或理论上面临什么问题。背景要尽快落到本文研究对象，不要使用过长的宏观叙述。

### 第二部分：相关研究
按方法或研究问题分类，例如：
- 基于模型的控制方法。
- 自适应或鲁棒控制方法。
- 神经网络或模糊系统近似方法。
- 滑模及高阶滑模方法。
- 网络化控制、时滞补偿或事件触发机制。

分类必须根据实际文献调整。每类工作都要说明代表性方法解决了什么，以及依赖哪些条件。

### 第三部分：研究不足
研究不足应当具体，例如：
- 某类方法依赖较强的模型先验。
- 某项结论只在特定时滞条件下成立。
- 现有设计未同时处理某些约束。
- 理论结果与网络传输或执行器实际输入之间存在建模差异。

以上只是可能的分析角度，不能在没有文献证据时直接写成领域事实。

### 第四部分：本文工作与贡献
先用一段话说明本文要解决的问题和采用的总体方法，再用编号条目总结贡献。每条贡献尽量包含“做了什么 + 得到了什么可验证结果”，避免只写使用了哪些技术名词。

## 3. Problem Formulation 写作检查

### 系统模型
- 明确状态向量、速度向量、控制输入、外部扰动和未知项。
- 说明变量维度、坐标系、单位和物理意义。
- 区分运动学模型与动力学模型。
- 说明模型是连续时间、离散时间还是混合系统。
- 所有时变参数都应明确时间依赖关系。

### 时滞系统
如果模型中存在输入时滞或通信时滞，必须说明：
- 时滞作用于状态、控制输入还是测量信号。
- 时滞函数的上下界。
- 是否对时滞导数作出限制。
- 控制器计算时使用的是当前输入、历史输入还是采样保持输入。
- 网络传输指令与实际执行器输入之间的关系。

不要把以下概念混为一谈：
- 输入时滞与状态时滞。
- 通信延迟与执行器动态。
- 采样保持与连续控制输入。
- 发送端控制指令与实际施加到对象上的输入。

### 假设
每条假设建议包含：
1. 明确的数学表达。
2. 物理或理论含义。
3. 后续在哪个定理或推导中使用。

不要为了让证明成立而在写作阶段临时添加没有研究依据的假设。若证明确实依赖额外条件，应将其标记为理论问题，交由研究者确认。

## 4. Controller Design 写作检查

建议先解释设计思路，再给公式，不要一上来连续堆叠控制律。

每个控制器或算法模块至少交代：
- 设计目标。
- 误差变量或变换变量的定义。
- 控制律或更新律。
- 参数的含义和取值条件。
- 与其他模块的关系。
- 实际实现所需的信息。

### 自适应控制
说明自适应参数估计什么、更新律如何构造、参数是否投影或受限，以及证明中如何处理参数误差。不能仅凭参数有界就声称估计值收敛到真实参数。

### RBF 神经网络
说明输入向量、基函数、中心、宽度、权值和逼近区域。区分理想权值、在线估计权值和逼近残差。若只假设残差有界，就不能写成网络能够精确重构未知函数。

### 滑模控制
说明滑模变量、到达律、切换项和边界层（若有）。如果使用高阶滑模，应清楚说明阶次、辅助变量和相应的理论条件。不要把普通滑模控制与二阶滑模性质混用。

### 事件触发机制
明确触发误差、触发阈值、触发条件、更新时刻和保持策略。若论文声称通信次数减少，应给出统计口径或对比依据；若声称无 Zeno 行为，应给出理论证明。

## 5. Stability Analysis 写作检查

稳定性章节的首要任务是准确表达已有证明，而不是把证明改写得更漂亮。

建议采用以下组织方式：
1. 列出本定理使用的假设和前置引理。
2. 定义 Lyapunov 函数或 Lyapunov-Krasovskii 泛函。
3. 推导其导数或差分上界。
4. 逐项解释不等式和常数的来源。
5. 说明如何选择控制器参数或设计常数。
6. 得到定理结论。
7. 解释该结论在本文问题中的含义。

### 关键区分
| 数学性质 | 写作时不能混淆的内容 |
|---|---|
| 渐近稳定 | 误差随时间趋于零，不等同于有限时间到达 |
| 一致最终有界 | 误差最终进入有界集合，不等同于收敛到原点 |
| 实用稳定 / 实用收敛 | 结论通常涉及可调或给定的邻域界 |
| 有限时间稳定 | 到达时间有限，通常依赖初始状态 |
| 固定时间稳定 | 收敛时间上界不依赖初始状态 |
| 预设时间稳定 | 设计者预先指定时间界，必须有相应条件和证明 |

如果定理证明只得到最终有界，就不能在摘要或结论中写成精确渐近收敛。若得到的是目标时间后的实用收敛界，应明确时间界、误差界和成立条件。

### 时滞 Lyapunov 分析
- 检查泛函是否正定。
- 检查积分项上下限是否与时滞定义一致。
- 检查求导时的边界项。
- 检查时滞导数约束是否确实被使用。
- 检查交叉项估计、Young 不等式和矩阵不等式的条件。
- 检查最终界中的常数是否有明确定义。

### 非 Zeno 性质
- 明确事件触发时刻序列。
- 给出相邻触发时刻间隔的下界或其他严格论证。
- 核对该下界是否对所有允许轨迹成立。
- 仿真中观察到非零间隔不能代替数学证明。

## 6. Simulation / Experiments 写作检查

建议按“设置—对比—结果—解释”组织。

### 仿真设置
明确：
- 系统模型和参数。
- 初始状态和初始误差。
- 控制器参数与自适应参数。
- 扰动或不确定项。
- 时滞、采样周期、触发阈值或丢包设置（若存在）。
- 仿真时长、步长、求解器和软件环境。

### 对比方法
- 说明选择对比方法的理由。
- 尽量保证模型、初始条件和约束一致。
- 说明参数来源或调参原则。
- 不要只展示对本文有利的指标。
- 不得把不公平设置下的差异解释为方法优势。

### 结果解释
每张图建议回答：
1. 图中展示什么变量？
2. 横纵坐标、单位和图例是什么？
3. 可以直接观察到什么现象？
4. 该现象支持哪一项理论或性能判断？
5. 该图不能证明什么？

### 常见指标
仅在实际计算过时使用：
- 跟踪误差及其范数。
- 收敛时间或进入误差邻域的时间。
- 控制输入幅值。
- 控制输入变化率。
- 触发次数和平均触发间隔。
- 通信负担或数据传输量。
- 对比方法下的误差指标。

不要仅凭曲线视觉效果宣称“显著优于”。如需量化比较，应给出计算口径、统计结果和相同条件下的基准。

## 7. 公式、符号和图表的统一

建议建立符号表，并至少检查：
- 同一个符号是否在不同章节代表不同变量。
- 标量、向量、矩阵是否有一致的字体约定。
- 转置、范数、绝对值和矩阵特征值符号是否规范。
- 变量是否在首次使用前定义。
- 公式编号是否连续，正文引用是否准确。
- 图表中的符号、单位和正文是否一致。
- 参数表中的数值是否与仿真代码和最终图表一致。

任何公式的实质性修改都需要重新核对其后续推导，不能只修改单个公式而不检查依赖它的定理和仿真。

## 8. 常见审稿风险清单

提交前重点检查：
- 研究空白是否只是泛泛声称，缺少文献比较。
- 创新点是否只是把多种成熟技术组合在一起，却没有说明组合解决了什么问题。
- 假设是否过强、过多或缺少解释。
- 控制输入模型是否与网络和执行器实际机制一致。
- 定理是否遗漏条件或隐藏依赖。
- 稳定性结论是否被摘要和结论夸大。
- RBF 等近似方法是否遗漏残差项。
- 事件触发是否缺少非 Zeno 证明。
- 仿真是否缺少公平对比、参数解释或消融验证。
- 图表是否只展示有利结果。
- 结论是否超出仿真或实验覆盖范围。

发现这些风险时，应明确指出其影响，不要通过语言润色掩盖理论或实验缺口。

## 9. 最终交付前检查

论文进入投稿准备前，至少确认：
- [ ] 研究问题与贡献表达一致。
- [ ] 所有定理和证明均来自已确认版本。
- [ ] 公式、符号和假设前后一致。
- [ ] 所有数值均可追溯到数据、代码或图表。
- [ ] 所有参考文献均有真实来源。
- [ ] 摘要和结论没有夸大结果。
- [ ] 图表、公式和交叉引用准确。
- [ ] 目标期刊的最新指南已经核查，或明确标注尚未核查。
- [ ] 所有待确认项已处理或在交付说明中列出。
