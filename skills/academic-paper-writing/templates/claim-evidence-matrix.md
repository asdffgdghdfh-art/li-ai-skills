## 论断类型与核对方式

### 理论论断
检查是否有对应定理、引理、推导和完整条件。区分渐近稳定、一致最终有界、实用收敛、有限时间、固定时间和预设时间等性质。

### 数值论断
检查是否能从原始数据、计算脚本或最终图表中复现。确认单位、统计口径、初始条件和对比条件一致。

### 文献论断
检查是否能在真实文献中找到直接依据。不要把单篇论文的结果概括成整个领域的共识。

### 实验论断
检查实验平台、样本、设备、环境和操作过程是否真实记录。仿真不能作为实物实验的证据。

## 论断强度检查

| 表达 | 必须确认的证据 |
|---|---|
| 提出 / 设计 | 论文中确实给出了对应方法 |
| 有效 / 改善 | 有明确指标和比较依据 |
| 显著改善 | 有适当的定量比较或统计依据 |
| 鲁棒 | 有对应不确定性或扰动条件下的理论或实验支持 |
| 保证稳定 | 有完整定理及其适用条件 |
| 渐近收敛 | 证明误差趋于零 |
| 有限时间收敛 | 有有限到达时间证明 |
| 固定时间收敛 | 有与初始状态无关的时间上界 |
| 预设时间收敛 | 有预先指定时间及对应证明 |
| 首次提出 / 最优 | 有充分文献检索或严格最优性证明 |

## 最终核查

- [ ] 每个核心贡献都有对应证据。
- [ ] 每个强结论都有严格依据。
- [ ] 每个数值都能追溯到来源。
- [ ] 每个文献判断都有真实出处。
- [ ] 每个结论都保留了适用条件。
- [ ] 没有把待验证内容写成既成事实。
